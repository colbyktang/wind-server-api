# Wind Server API - Python Backend Instructions

## Project Overview
This is a Python FastAPI backend for the Wind Server application - a REST API for managing game servers. It provides authentication (JWT), blog functionality, and will expand to include game server management features.

## Tech Stack
- **Framework**: FastAPI
- **Python Version**: 3.11+
- **Database**: SQLAlchemy ORM (database type configurable)
- **Authentication**: JWT with bcrypt password hashing
- **Server**: Uvicorn ASGI server
- **Environment**: python-dotenv for configuration

## Project Structure
```
app/
├── __init__.py
├── main.py              # FastAPI app, middleware, root endpoints
├── database.py          # SQLAlchemy database configuration
├── models.py            # Shared database models
├── auth/                # Authentication module
│   ├── auth_models.py   # User models
│   ├── auth_routes.py   # Login/register/refresh endpoints
│   ├── security.py      # JWT & password utilities
│   └── [schemas].py     # Pydantic request/response models

│   ├── blog_models.py   # Blog database models
│   ├── blog_routes.py   # Blog CRUD endpoints
│   └── blog_schemas.py  # Blog Pydantic schemas
└── vault/               # HashiCorp Vault integration (future)
```

## Architecture Patterns

### Modular Design
Each feature area (auth, blog, etc.) is a separate module with:
- `*_models.py` - SQLAlchemy ORM models
- `*_routes.py` - FastAPI router with endpoints
- `*_schemas.py` - Pydantic models for validation

### Dependency Injection
FastAPI's dependency system is used for:
- Database sessions: `db: Session = Depends(get_db)`
- Authentication: `current_user = Depends(get_current_user)`

### Router Pattern
Each module defines an `APIRouter` that's registered in `main.py`:
```python
from app.blog.blog_routes import router as blog_router
app.include_router(blog_router)
```

## Coding Conventions

### File Naming
- Models: `feature_models.py`
- Routes: `feature_routes.py`
- Schemas: `feature_schemas.py`
- Snake_case for all Python files

### Code Style
- Follow PEP 8 style guide
- Use type hints for all function signatures
- Docstrings for all public functions/classes
- Maximum line length: 88 (Black formatter default)
- Prefer f-strings for string formatting

### Import Organization
```python
# Standard library
from datetime import datetime, UTC

# Third-party
from fastapi import FastAPI, Depends, HTTPException
from sqlalchemy.orm import Session

# Local
from app.database import get_db
from app.models import User
```

### Models (SQLAlchemy)
```python
from sqlalchemy import Column, Integer, String, DateTime
from app.database import Base

class ModelName(Base):
    __tablename__ = "table_name"
    
    id = Column(Integer, primary_key=True, index=True)
    created_at = Column(DateTime, default=lambda: datetime.now(UTC))
```

### Schemas (Pydantic)
```python
from pydantic import BaseModel, Field

class SchemaName(BaseModel):
    field: str = Field(..., description="Field description")
    
    class Config:
        from_attributes = True  # For ORM mode
```

### Routes (FastAPI)
```python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session

router = APIRouter(prefix="/api/feature", tags=["feature"])

@router.get("/items", response_model=list[ItemSchema])
def get_items(db: Session = Depends(get_db)):
    """Get all items with proper error handling"""
    return db.query(Item).all()
```

## Database Conventions

### Naming
- Table names: lowercase, snake_case, plural (e.g., `users`, `blog_posts`)
- Column names: lowercase, snake_case
- Foreign keys: `{table_singular}_id` (e.g., `user_id`)

### Timestamps
Always include `created_at` and `updated_at` where applicable:
```python
created_at = Column(DateTime, default=lambda: datetime.now(UTC))
updated_at = Column(DateTime, onupdate=lambda: datetime.now(UTC))
```

### Relationships
Use SQLAlchemy relationships with proper lazy loading:
```python
posts = relationship("BlogPost", back_populates="author")
```

## Authentication & Security

### Password Hashing
- Use bcrypt via `security.py` module
- Never store plain text passwords
- Always hash passwords before storing

### JWT Tokens
- Access tokens: Short-lived (configurable, default 30 min)
- Refresh tokens: Longer-lived (configurable, default 7 days)
- Include user info in token payload
- Validate tokens in `get_current_user` dependency

### Protected Endpoints
```python
@router.get("/protected")
def protected_route(current_user = Depends(get_current_user)):
    return {"user": current_user.username}
```

### CORS Configuration
- Configure allowed origins via environment variable `ALLOWED_ORIGINS`
- Default: `http://localhost:4200` (Angular dev server)
- Production: Set to actual frontend domain

### Security Headers
Security headers middleware adds:
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `Strict-Transport-Security: max-age=31536000`

## Environment Variables
Create a `.env` file (never commit to git):
```
DATABASE_URL=sqlite:///./wind_server.db
SECRET_KEY=your-secret-key-here
ALLOWED_ORIGINS=http://localhost:4200
ACCESS_TOKEN_EXPIRE_MINUTES=30
REFRESH_TOKEN_EXPIRE_DAYS=7
```

## API Response Patterns

### Success Responses
```python
# Single item
return {"id": 1, "name": "Item"}

# List
return [{"id": 1}, {"id": 2}]

# Created (201)
return JSONResponse(
    status_code=status.HTTP_201_CREATED,
    content={"id": new_item.id}
)
```

### Error Responses
```python
# 400 Bad Request
raise HTTPException(400, detail="Invalid input")

# 401 Unauthorized
raise HTTPException(401, detail="Invalid credentials")

# 404 Not Found
raise HTTPException(404, detail="Resource not found")

# 500 Internal Server Error (let FastAPI handle)
```
